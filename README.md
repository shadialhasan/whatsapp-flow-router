# 💬 whatsapp-flow-router

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: WhatsApp Cloud API](https://img.shields.io/badge/WhatsApp-Cloud%20API-green.svg)](https://developers.facebook.com)

A state-machine conversational router for WhatsApp Cloud API. Enables lead qualification, menu trees, and support workflows without costly closed-source bot builders.

```bash
npm install
node server.js
```
